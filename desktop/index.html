Mining configuration

This build mines RandomX (rx/0) only.

Pool ranking uses measured hashrate affinity — not a payout guarantee (#42).

Monero addresses start with 4 or 8 and are 95 characters.

Leaving one thread free keeps the desktop responsive.

Scratchpad is ~2 MiB per thread — not the full Fast-mode RAM requirement (#35).

Not saved yet

Wownero and DERO cannot be mined by this build. Both need work that is not written yet: Wownero a verified signer/daemon flow (#28), DERO its own daemon adapter (#27).

Idle & window policy

Maps to XMRig pause-on-active / pause-on-battery where the OS supports them (#77). Linux does not claim native pause-on-active.

Ignored with a clear degradation note when unsupported.

Never defaults to hide-and-mine.
