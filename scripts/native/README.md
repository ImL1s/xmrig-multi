## Artifacts

- `app/src/main/assets/xmrig_arm64` — packaged engine
- `app/src/main/assets/native-capabilities.json` — generated by `scripts/native/generate-manifest.sh`
- `scripts/native/versions.env` — pinned versions/hashes
- `scripts/native/smoke-report.md` — structural/negative smoke (not deviceVerified)

## Rebuild

```bash
export ANDROID_NDK_HOME=/path/to/android-ndk-r26c
./scripts/build_xmrig.sh
./scripts/native/smoke-native.sh
```

Uses an isolated `mktemp` work dir + trap cleanup. Set `KEEP_XMRIG_WORK=1` to inspect intermediates.

## App gates

`XmrigNativeCapabilities` loads the manifest and verifies the binary SHA-256. Mismatch → restricted mode (TLS/HTTP/benchmark/daemon UI locked; Monero start via process relaunch still allowed).

## Evidence boundary

`deviceVerified` stays `false` until an OEM device report is attached. Host smoke + CI `native-rebuild` job are structural evidence only.
